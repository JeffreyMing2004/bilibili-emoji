# B站表情包工坊 (bilibili-emoji)

帮助 UP 主 / 主播把任意图片一键转换成符合 **哔哩哔哩直播间表情包** 和 **充电专属表情包** 要求的尺寸与体积。

因为两类表情包对像素尺寸、文件大小的要求不同（且官方数字可能随时间调整），本工具把规格做成**可编辑的预设**：选一个场景 → 拖图进来 → 自动缩放 + 压缩 → 批量下载，全程在浏览器本地完成，**图片不会上传到任何服务器**。

## 功能

- **多图合一切图**（唯一上传方式）：画师把多张表情画在一张大图上交付时，放入整图后用**固定大小的方形截取框**对齐每格表情——框的位置大小固定，只能拖动底图（滚轮缩放对齐格宽，方向键 1px 微调，Shift+方向键 10px），逐张"截取这张表情"；也可直接 `Ctrl+V` 粘贴整图
- 三种预设：直播间表情（默认 162×162 / ≤16kb）/ 充电专属表情 / 充电表情包封面，尺寸、体积上限、填充方式均可改并自动记住
- 自动适配：非正方形图可选 留白（透明/纯色）/ 居中裁剪 / 拉伸
- 智能压缩：先尝试真彩色 PNG，超限时用调色板量化并**二分搜索颜色数**，在满足体积上限的前提下尽量保画质（例：640×640 噪点图 → 162×162 / 16KB 上限下自动压到 15.9KB / 23 色）
- 每张图显示 原图 vs 处理后 对比、是否达标徽标；支持单张下载与一键 ZIP 打包（自动处理重名）
- **改名**：结果卡片上点 ✏️ 直接修改每张表情的文件名（下载时自动带 `_尺寸` 后缀）
- **内容居中检测**：自动判断表情内容是否在画布正中（透明留白图显示偏移方向与像素数），设置里可开启"自动居中"一键修正
- **直播间预览**：每张表情可打开模拟 B 站直播聊天栏的效果预览，看表情发到直播间的大致样子
- 改任意设置或切换预设后，已添加的图片（含切图条目）自动重新处理

## 内置规格（默认值）

| 类型 | 格式 | 尺寸 | 体积 | 数量 | 上传入口 |
| --- | --- | --- | --- | --- | --- |
| 直播间表情 | PNG | 162×162px | ≤16kb（社区经验值） | — | 直播中心 → 我的直播间 → 直播表情 |
| 充电专属表情 | PNG | 162×162px | ≤300kb | 每套 ≤10 张 | 创作中心 → 充电计划 → 专属表情包 |
| 充电表情包封面 | PNG | 360×360px | ≤300kb | 每套 1 张 | 同上 |

> 充电表情包规格来自 B 站官方专栏 [cv23736558](https://www.bilibili.com/read/cv23736558)；直播间表情官方数字未公开确证，社区经验按 162×162 / 16kb 以下制作最稳妥过审——如与直播中心页面提示不同，在工具里改一次即可，设置会记住。

## 使用

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 产出静态站点到 dist/，可部署到任意静态托管
```

## 技术栈与实现要点

- Vue 3（`<script setup>` 组合式 API）+ Vite，无 UI 框架，B 站粉主题
- `upng-js`：PNG 编码 + 调色板量化（体积控制的核心）
- `jszip`：批量打包
- 处理管线在 [`src/lib/process.js`](src/lib/process.js)：`loadImage → drawSquare / drawRegion（canvas 适配+缩放）→ UPNG.encode（真彩色 → 超限则二分颜色数量化）`
- 切图编辑器 [`src/components/SpriteEditor.vue`](src/components/SpriteEditor.vue)：底图用 CSS transform（translate + scale）渲染，固定方框叠加层 + 大面积暗化遮罩；拖动带边界钳制（截取区域永远完整落在图片内），滚轮缩放以框中心为锚点
- 已知限制：动图（GIF / 动图 WebP / APNG）仅取第一帧输出静态 PNG（B 站两类表情包均要求 PNG 静态图）
- 测试图片生成：`node scripts/make-test-images.mjs`（纯 Node 手写 PNG，无第三方依赖）
